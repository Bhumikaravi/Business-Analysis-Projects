# Business Analytics – Power BI Retail Sales Dashboard

## 📌 Project Overview

This project focuses on integrating business data from multiple sources into **Microsoft Power BI** for retail sales analysis.

The data was collected from **CSV/Excel files and a MySQL database**, cleaned and transformed using Power Query, and then modeled in Power BI to create an interactive business dashboard.

The main objective is to analyze **sales performance, customer behavior, product performance, store performance, and regional sales trends**.

## 🎯 Objectives

* Import business data from CSV/Excel files and MySQL.
* Connect multiple data sources with Power BI.
* Clean and transform the data using Power Query.
* Create relationships between business tables.
* Analyze retail sales and customer information.
* Develop an interactive 3-page Power BI dashboard.
* Generate meaningful business insights for decision-making.

## 🗂️ Data Sources

The project uses two main data sources:

### 1. MySQL Database

* Created a custom MySQL database.
* Created tables and records using SQL queries.
* Stored and retrieved required retail business data.

### 2. CSV/Excel Files

* Imported additional retail data into Power BI.
* The data contains information about:

  * Products
  * Customers
  * Stores
  * Sales transactions

## 🔄 Data Preparation

The data was prepared using **Power Query Editor**.

The following operations were performed:

* Checked and corrected data types.
* Removed unnecessary data.
* Removed duplicate records.
* Cleaned the data.
* Applied the transformations before loading the data into Power BI.

## 🔗 Data Modeling

Relationships were created between the main business tables:

* **Sales**
* **Customer**
* **Product**

One-to-many relationships were verified to ensure proper data analysis.

## 📊 Dashboard Features

The Power BI dashboard consists of **3 pages**:

### 1. Sales Analysis

* Total Sales
* Total Quantity
* Total Orders
* Product-wise Sales
* Category-wise Sales
* City-wise Sales
* Monthly Sales Trends

### 2. Customer Analysis

* Customer Segments
* Gender Analysis
* Payment Method Analysis
* Age Group Analysis
* Customer Sales Contribution

### 3. Store & Regional Analysis

* Store-wise Sales
* Mall vs Standalone Store Performance
* Sales by City
* Orders by City
* Regional Performance

### 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

* Month-Year
* Category

These filters allow users to explore the data dynamically.

## 💡 Business Insights

The dashboard helps identify:

1. **Product Performance** – Top-selling and low-selling products.
2. **Store Performance** – Sales comparison between different stores.
3. **Customer Analysis** – High-value customers and their contribution to sales.
4. **Sales Trends** – Sales patterns across different time periods.
5. **Business Growth Opportunities** – Areas for improving sales, inventory, and customer targeting.

## 📈 Final Outcome

The project successfully integrates data from multiple sources into Power BI and converts the data into meaningful business insights.

The final dashboard provides a centralized view of **sales, customers, products, stores, and regional performance**, helping management monitor business performance and support data-driven decision-making.
